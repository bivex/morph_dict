# Spanish Morphological Dictionary Data

Source: [UniMorph Spanish](https://github.com/unimorph/spa) (1.2M forms)

Converter: `dev/spa_conv/unimorph_spa_to_aot.py`

## Stats
- 65,020 lemmas
- ~1.19M word forms
- 7,030 flexia models (paradigms)
- 144 grammatical codes

## Files
- `gramtab.json` — grammatical codes (POS + grammems)
- `morphs.json` — morphological paradigm data (generated by converter)
- `project.mwz` — project configuration for morph_wizard/morph_gen
- `WordData.txt` — word frequency data (empty — no corpus)
- `StatData.txt` — statistical data (empty)

## Building
```bash
./Scripts/dict_rebuild/rebuild_spanish_dicts.sh --skip-build
```

## Regenerating from UniMorph
```bash
python3 dev/spa_conv/unimorph_spa_to_aot.py
```
