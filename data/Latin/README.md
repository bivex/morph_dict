# Latin Morphological Dictionary Data

Source: [UniMorph Latin](https://github.com/unimorph/lat)

Converter: `dev/lat_conv/unimorph_lat_to_aot.py`

## Files
- `gramtab.json` — grammatical codes (POS + grammems)
- `morphs.json` — morphological paradigm data (generated by converter)
- `project.mwz` — project configuration for morph_wizard/morph_gen
- `WordData.txt` — word frequency data (empty)
- `StatData.txt` — statistical data (empty)

## Building
```bash
./Scripts/dict_rebuild/rebuild_latin_dicts.sh --skip-build
```

## Regenerating from UniMorph
```bash
python3 dev/lat_conv/unimorph_lat_to_aot.py
```
