# French Morphological Dictionary

Built from [UniMorph French](https://github.com/unimorph/fra) verb conjugation data
plus closed-class words (articles, determiners, prepositions, pronouns, conjunctions, adverbs).

Converter: `dev/fre_conv/unimorph_fre_to_aot.py`
Rebuild: `Scripts/dict_rebuild/rebuild_french_dicts.sh`
