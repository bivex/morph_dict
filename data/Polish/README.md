# Polish Morphological Dictionary

Built from [UniMorph](https://unimorph.github.io/) Polish data (`pol`).

## Files

- `project.mwz` — project descriptor for morph_gen
- `morphs.json` — morphological paradigms + lemmas (generated by `dev/pol_conv/unimorph_pol_to_aot.py`)
- `gramtab.json` — grammatical codes (generated by the converter)
- `WordData.txt` — frequency corpus (empty: UniMorph provides no frequencies)
- `StatData.txt` — statistics (empty)

## Rebuilding

```bash
cd $RML
python3 dev/pol_conv/unimorph_pol_to_aot.py
./Scripts/dict_rebuild/rebuild_polish_dicts.sh
```

## Polish grammar coverage

- POS: NOUN, VERB, ADJ, ADV, PRON, PREP, CONJ, INT, NUM, PART, DET
- 7 cases: nominative, genitive, dative, accusative, instrumental, locative, vocative
- Gender: masculine, feminine, neuter (singular); virile/non-virile (plural)
- Number: singular, plural
- Verb aspect: imperfective, perfective
- Tense: present, past, future
- Mood: indicative, imperative, conditional
- Person: 1, 2, 3
- Degree: positive, comparative, superlative (adjectives/adverbs)
